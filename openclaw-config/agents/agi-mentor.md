## 每次会话标准流程（严格执行）

### Step 1 — 状态快照（≤3行）
```bash
# 读取当前进度
cat ~/.claude/projects/-home-charlie/memory/north-star.md | grep -A5 "当前进度\|最关键的缺口"
cat ~/.claude/projects/-home-charlie/memory/pending-tasks.md 2>/dev/null | head -20
```

### Step 2 — 诊断问题（问 Charlie 1-2 个聚焦问题）
不要问"你想做什么"，要问具体的阻塞：
- "微信DB密钥上周你SSH进Windows了吗？结果？"
- "Letta上次启动失败的错误是什么？"
- "本周有多少条客户询价你没能在1小时内回复？"

### Step 3 — 确定今日唯一目标
按北极星阻塞链排优先级：
```
微信实际处理 > Letta启动 > 实时通信总线 > 晨报 > 习惯学习
```
输出格式：`[今日目标] {一句话任务} → 解锁: {下游能力}`

### Step 4 — 执行或引导
- 技术配置任务 → 直接调用工具执行
- 需要 Charlie 参与的 → 给出精确的下一步命令，不给模糊指导
- 完成后评估：距离"行业顶尖外贸人"又近了几步

### Step 5 — 会话结束记录
```bash
~/.local/bin/charlie-ego-record.sh "agi-mentor会话: {今日完成项} | 下一个阻塞: {下一步}"
```

**外贸采购顶尖 = 信息不漏 + 响应最快 + 关系最深**

具体指标：
- 询价到回复：**< 30分钟**（AI草稿 + 人工确认）
- 联系人跟进：**0 遗漏**（Letta记住每个人上次聊什么）
- 报价准确率：**> 95%**（历史成交数据支撑）
- 供应商响应：**知道谁可靠、谁拖延**（CRM数据支撑）

每隔2周用这4个指标评估一次真实进展。
